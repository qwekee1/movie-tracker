# Movie Tracker
Персональный трекер фильмов и сериалов.

### Как пользоваться:
1. Добавляйте фильмы через кнопку "Добавить".
2. Перетаскивайте карточки между колонками.
3. Нажмите правой кнопкой мыши на карточку, чтобы отредактировать или удалить.
4. Данные сохраняются автоматически в вашем браузере.
